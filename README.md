# Tom Troc

Pour installer et exécuter ce projet :

**Cloner ou copier les fichiers du projet**  
Placez vous dans le répertoire `/C:/xampp/htdocs/` et clonez ou copiez le projet.

**Base de données**  

- Créez une base de données MySQL `tomtroc`.
- Importez le fichier SQL fourni : tomtroc.sql.

**Lancer le projet**

- Démarrez Apache et MySQL via XAMPP.
- Dans votre navigateur, allez à l’adresse : http://localhost:8080/tomtroc/public/index.php_(remplacez `8080` par votre port Apache si différent)_
